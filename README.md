# 看穿這一局

網路交友與性影像誘騙防制｜國小高年級・國中互動教材

> 最危險的，常常不是一開口就很噁的那種人。
> 是那個跟你很合、很懂你、讓你覺得「他不一樣」的人。

**線上使用：** https://10033641tycg.github.io/see-the-hook/

---

## 這是什麼

一套用手機聊天介面呈現的互動教材。孩子在社群或遊戲裡發文交朋友，遇到一個溫和、有共同話題、說自己年紀差不多的網友，接下來幾天的對話會一步步把界線往後推。孩子在每個關鍵時刻自己選擇怎麼回，玩完後看到自己的選擇被拆解，以及自己最容易在哪一種時刻被帶著走。

情境取材自兒少性剝削實務案件的常見型態，加以改編、虛構，不代表任何特定個案，不含露骨內容。

## 適用對象與使用原則

- 對象為**國小高年級**與**國中**學生，進入時可選年齡與性別，劇情共用，性別只改變對方的身分設定。
- **用於個案或國小學童時，請由受過訓練的專業人員全程陪同**，不要讓孩子單獨使用。內容會模擬被引導、索取影像的過程，可能勾起曾有相關經驗者的情緒，陪同者需準備好即時接住與引導。
- 適合的場景：兒少保護個案工作中的輔助談話、小團體或課堂的預防宣導（建議搭配討論）、專業人員訓練。

## 四個關卡

| 關卡 | 情境 | 想讓孩子帶走的一句 |
|---|---|---|
| 想認識我的加我 | 發文交朋友，一堆怪人被擋掉，留下一個「不一樣」的人 | 最危險的，常常是讓你覺得「他跟別人不一樣」的那個 |
| 混熟的這幾天 | 每天陪你聊、說你很成熟、要你保密，話題慢慢轉向身體 | 知道你幾歲還跟你聊身體的人，就是有問題的人 |
| 拍一張就好 | 開口要照片，「只有我看」，不然就不理你 | 開口要照片的人才是犯法的，不是你 |
| 已經傳了之後 | 被威脅、怕被罵、覺得「都是我自己傳的」 | 就算是你自己傳的，錯的也是要的那個人 |

四關都完成後會解鎖「看看你是哪種人」統整報告，整理孩子跨四關最容易中招的類型：想被注意被喜歡、怕他不理我、被說「你很成熟」、怕被罵所以藏起來。

## 設計理念

**記得住比答得對重要。** 每關結束最先看到的是一句很短的話，目標是讓孩子在真實遇到時想得起來；較長的拆解與討論題主要給陪伴的大人使用。

**灰色選項。** 每題三個選項，除了守住與被帶走，還有一個「看起來像拒絕、其實留了一條縫」的選項，例如換話題、說會考慮、說不會主動講。這是孩子在真實情境最常見的反應，也最常被對方利用。

**對方的語氣會跟著孩子的選擇變。** 孩子拒絕，對方轉冷或加壓；孩子留縫，對方順勢往前推。但不管對方多兇，守住界線永遠是對的選擇。

**不檢討孩子。** 所有回饋避免「你錯了」的語氣，選到被帶走的選項時，回饋是「這不是你的錯，是他太會包裝」。第四關特別針對已經傳過照片的孩子設計，核心訊息是錯的是索取的人。

**求助不預設是父母。** 研究顯示受害兒少最不願意向家長求助，因此教材一律列出老師、輔導老師、社工與 113，並明說不一定要先跟爸媽講。

## 給陪伴者的功能

- **檢視結果**：訊息列表中的「檢視結果（陪伴的大人看）」會保留孩子**第一次**自己作答的內容，重玩不會覆蓋，方便事後一起回顧。建議問法是「當下那一句，你心裡在想什麼？」而不是「你為什麼選這個？」
- **清除紀錄**：訊息列表最下方，換下一位孩子使用前請先清除。
- **資料不外傳**：作答與使用者資訊只存在該裝置的瀏覽器中，不會上傳到任何地方。
